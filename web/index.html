How does a rolling droplet sound?

Pure Web Audio demo — modal, drip and granular primitives ported from the Python physics engine. Optional convolution reverb. No backend.

Click a slider, then Render. The first click also unlocks the audio context (browser policy). Use headphones.

Modal impact — banked biquads excited by a noise burst

Pick a material profile, shape the exciter, listen. Equivalent to the Python synth_modal_impact.

Drip event — Minnaert chirp + surface tail + bubble pop

Equivalent to Python synth_drip_event.

Granular flow — stochastic cloud of micro-impacts

Pebbles, sand, ice shards, ash... each grain is a tiny damped sinusoid pre-mixed into an AudioBuffer manually for efficiency (no thousands of OscillatorNodes). Equivalent to Python synth_granular_flow.

Rolling droplet — quasi-periodic train of drip events

The starring case of the paper. Each contact is one inline drip event (Minnaert chirp + surface modal tail) summed directly into the output buffer with timing jitter. Equivalent to Python synth_rolling_droplet.

Friction — scrape, drag, sliding contact

Noise modulated by a velocity envelope with stick-slip dynamics, bandpass-filtered by the surface material, then routed through a multi-mode body resonator bank. Micro-impacts added at high roughness. Equivalent to Python synth_scrape.

Splash — liquid impact burst

A whoosh pre-impact followed by a cascade of bubbles (microbubbles first, larger bubbles later) with subsurface agitation. Equivalent to Python synth_splash.

Pour — continuous liquid stream

A dense train of drip events (30–230 Hz) with a turbulence noise bed. Like rolling droplet but much denser and wetter. Equivalent to Python synth_pour.

Global reverb (applied to any render)

Synthetic IRs convolved via ConvolverNode. Set mix to 0 to bypass.

Procedural synthesis, pure DSP, no neural networks. Source: this folder.
